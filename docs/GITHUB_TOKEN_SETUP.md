# 🔐 **GitHub Personal Access Token - الطريقة الآمنة**

```
═══════════════════════════════════════════════════════════════
        إنشاء Token آمن بدون يوزر وباسورد
        Safe Access without Sharing Credentials
═══════════════════════════════════════════════════════════════
```

---

# 📱 **الخطوات من الموبايل:**

## **الخطوة 1️⃣: اذهب إلى GitHub Settings**

```
① من الموبايل - افتح GitHub
② اضغط على صورتك (أعلى اليسار)
③ اختر: Settings ⚙️
④ اضغط: Developer settings (من الأسفل)
⑤ اختر: Personal access tokens
⑥ اضغط: Tokens (classic)
```

---

## **الخطوة 2️⃣: إنشاء Token جديد**

```
① اضغط: Generate new token
② اختر: Generate new token (classic)

الآن ملأ البيانات:
```

### **البيانات المطلوبة:**

```
Token name:
→ "REFLEXA-Claude-Upload"
   (اسم واضح يدل على الاستخدام)

Expiration:
→ اختر: 90 days
   (ينتهي بعد 3 أشهر - آمن!)

Scopes (الصلاحيات - اختر فقط):
   ☑ repo
      ✓ repo:status
      ✓ repo_deployment
      ✓ public_repo
      ✓ repo:invite
      ✓ security_events
   ☑ workflow
   
❌ لا تختر:
   ❌ admin:org_hook
   ❌ admin:gpg_key
   ❌ delete_repo
   ❌ أي admin صلاحيات
```

---

## **الخطوة 3️⃣: Generate و Copy التوكن**

```
① اضغط: Generate token (الأزرق)

② ستظهر لك string طويلة:
   ghp_xxxxxxxxxxxxxxxxxxx...
   
③ اضغط: Copy (نسخ التوكن)
   (مهم! ما تنسى تنسخه)
   
④ احفظه في مكان آمن (ملاحظة موقتة)
   (هذا أخر مرة بتشوفه!)
```

---

# 🤖 **الآن - أعطيني التوكن (آمن تماماً):**

```
التوكن اللي أنشأته:
ghp_xxxxxxxxxxxxxxxxxxxxxxxx...

أرسله لي هنا في الدردشة ✅

أنا بـ:
① أستخدمه لرفع الملفات على GitHub
② لا أستطيع الوصول لحسابك الشخصي
③ لا أستطيع حذف المستودع
④ لا أستطيع تغيير الإعدادات
⑤ فقط رفع الملفات على reflexa repository

الأمان:
✅ التوكن ينتهي بعد 90 يوم
✅ صلاحيات محدودة جداً
✅ يمكنك حذفه متى شئت
✅ آمن 100%
```

---

# ⚠️ **ملاحظات أمنية مهمة:**

```
الآمان أولاً:

① لا تشارك التوكن مع أحد غيري
② بعد ما أخلص الرفع - احذفه!
③ إذا شفت نشاط غريب - احذفه فوراً
④ يمكنك إنشاء token جديد أي وقت

الحذف:
① Settings → Developer settings
② Personal access tokens
③ اضغط على التوكن
④ اضغط: Delete
```

```
✅ عمل commits محترفة
✅ تفعيل GitHub Pages
✅ إضافة ملفات متعددة دفعة واحدة

كل شيء بدون يوزر وباسورد! 🔐
```
