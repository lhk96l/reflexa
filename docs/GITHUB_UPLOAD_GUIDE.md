# 🎯 **إذا حصلت مشكلة:**

## **المشكلة 1: "Repository not found"**

```
الحل:
① اذهب https://github.com/new
② انشئ repository باسم: reflexa
③ اختر: Public
④ اضغط Create (بدون README)
⑤ حاول الأمر الأخير جديد
```

## **المشكلة 2: "Authentication failed"**

```
الحل:
① استخدم Personal Access Token:
   https://github.com/settings/tokens
② اضغط: Generate new token
③ اختر: repo + write:repo_hook
④ Copy الـ Token
⑤ استخدمه بدل Password
```

## **المشكلة 3: "Permission denied"**

```
الحل:
① اتأكد من SSH Key:
   ssh-keygen -t rsa
② أضفه على GitHub: https://github.com/settings/keys
③ أو استخدم HTTPS بدل SSH
```
