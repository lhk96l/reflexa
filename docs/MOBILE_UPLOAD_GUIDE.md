## **الخطوة 3️⃣: Create Repository**

```
① اضغط: + (أعلى اليمين)
② اختر: New repository

## **الخطوة 4️⃣: رفع الملفات**

```
① في صفحة Repository الجديدة
② ابحث عن زر: "Upload" أو "Add file"
③ اختر: "Upload files"
④ اختر من الملفات:
   - index.html
   - manifest.json
   - README.md
   - css/ (المجلد)
   - js/ (المجلد)
⑤ اضغط: Commit changes
```

## **الخطوة 5️⃣: Enable GitHub Pages**

```
① اذهب: Settings ⚙️
② ابحث عن: Pages
③ تحت Source اختر:
   - Branch: main
   - Folder: / (root)
④ Save
⑤ انتظر دقيقة واحدة
⑥ سيقول: "Your site is published at:"
   https://lhk96l.github.io/reflexa/
