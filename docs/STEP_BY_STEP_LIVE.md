# 📱 **الخطوة 1️⃣: افتح متصفح الموبايل (الآن!)**

```
اضغط على:
🔵 Chrome أو Safari أو أي متصفح عندك

ثم اكتب في العنوان:
→ github.com
```

**⏰ الوقت: 30 ثانية**

---

# 🔑 **الخطوة 2️⃣: تسجيل الدخول (Login)**

```
عندما تفتح github.com ستشوف الصفحة الرئيسية

اضغط: Sign in (أعلى اليمين)

ثم ادخل:
├─ Username: lhk96l
├─ Password: (كلمة مرورك)
└─ اضغط: Sign in
```

**✅ الآن أنت في حسابك**

**⏰ الوقت: 1 دقيقة**

---

# ➕ **الخطوة 3️⃣: إنشاء Repository جديد**

```
بعد ما تسجل الدخول:

1️⃣ في أعلى الصفحة - اضغط على الـ "+" (إضافة)
   (في القائمة العلوية)

2️⃣ اختر: "New repository"

3️⃣ الآن ستشوف form للـ Repository الجديد
```

**⏰ الوقت: 30 ثانية**

---

# 📝 **الخطوة 4️⃣: ملء بيانات Repository**

```
في الـ form اكتب:

1. Repository name:
   → reflexa
   (بدون مسافات، بحروف صغيرة)

2. Description:
   → Advanced Network Diagnostic Tool
   (اختياري لكن أضفه)

3. Public or Private:
   → اختر: ⭕ Public (عام)
   (مهم جداً!)

4. Add a README file:
   → ✓ بدون ما تختاره (unchecked)
   (سنضيفه بعدين)

5. Choose a license:
   → MIT License
   (مهم للحماية!)

بعدين اضغط:
   → "Create repository"
```

**✅ Repository جديد تم إنشاؤه!**

**⏰ الوقت: 2 دقيقة**

---

# 📂 **الخطوة 5️⃣: رفع الملفات**

```
بعد ما تضغط Create:
ستشوف صفحة Repository جديدة فارغة

ابحث عن زر: "Upload files" أو "Add file"
(عادة في الوسط أو أعلى قليل)

اضغط عليه
```

**ستفتح لك صفحة الرفع**

**⏰ الوقت: 30 ثانية**

---

# 📤 **الخطوة 6️⃣: اختر الملفات من الموبايل**

```
في صفحة الرفع:

1. اضغط: "Choose your files" أو "Select files"
   (ستفتح لك ملفات الموبايل)

2. اختر الملفات التالية:
   ✓ index.html
   ✓ manifest.json
   
3. اضغط: Upload أو Open

ستشوف التحميل يبدأ

4. بعد ما ينتهي من الملفات الأول:
   اضغط: "Commit changes"
```

**النتيجة: الملفات الأساسية رفعت! ✅**

**⏰ الوقت: 3-5 دقائق**

---

# 📁 **الخطوة 7️⃣: رفع باقي الملفات**

```
الآن نرفع المجلدات الأخرى:

① رح للـ Repository صفحة الرئيسية
② اضغط: "Add file" → "Upload files"
③ اختر المجلد: css/ (كاملاً)
④ اضغط Upload
⑤ اضغط Commit

ثم نفس الخطوات لـ:
├─ js/ (المجلد كامل)
├─ README.md
├─ ABOUT_US.md
├─ BRANDING_GUIDE.md
└─ باقي الملفات

(ممكن ترفع الملفات والمجلدات دفعة واحدة)
```

**النتيجة: جميع الملفات على GitHub! ✅**

**⏰ الوقت: 10 دقائق**

---

# 🔧 **الخطوة 8️⃣: تفعيل GitHub Pages (الأهم!)**

```
بعد ما تخلص من رفع الملفات:

1. اذهب صفحة Repository (الرئيسية)

2. ابحث عن: ⚙️ Settings
   (عادة في أعلى اليمين)

3. اضغط Settings

4. ابحث في القائمة اليسار عن: Pages
   (قد تحتاج تنزل قليل)

5. اضغط: Pages

6. تحت "Source":
   ✓ اختر Branch: main
   ✓ اختر Folder: / (root)

7. اضغط: Save

8. انتظر دقيقة واحدة...

9. ستظهر لك رسالة:
   "Your site is published at:
    https://lhk96l.github.io/reflexa/"

✅ موقعك عام الآن!
```

# 🚨 **إذا حصلت مشكلة:**

```

→ حاول مرة ثانية
```
