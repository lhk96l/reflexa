## 🔧 تثبيت واستخدام المشروع

### الخطوة 1: اختر مجلد للمشروع
```bash
cd ~/projects/
mkdir network-doctor-pro
cd network-doctor-pro
```

### الخطوة 2: انسخ جميع الملفات

قم بنسخ جميع الملفات من قائمة الملفات أعلاه إلى المجلد.

### الخطوة 3: تشغيل محلي (اختياري)

#### استخدام Python:
```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

#### استخدام Node.js:
```bash
npx http-server
# ثم افتح http://localhost:8080
```

### الخطوة 1: إنشاء المستودع على GitHub

1. اذهب إلى https://github.com/new
2. اسم المستودع: `network-doctor`
3. الوصف: `Advanced Network Diagnostic Tool - فاحص الشبكة المتقدم`

5. **لا تضيف** README/gitignore (سنضيفها نحن)
6. اضغط "Create repository"

### الخطوة 2: إعداد Git محلياً

```bash

cd network-doctor-pro

# هيئ Git
git init

git config user.email "your-email@gmail.com"

# أضف جميع الملفات
git add .

# إنشاء Commit الأول
git commit -m "feat: Initial release of Network Doctor v2.0.0

- Complete professional implementation
- Advanced speed testing

- Dark/Light mode
- PWA ready
- Responsive design"

# ربط مع GitHub
git remote add origin https://github.com/lhk96l/network-doctor.git
git branch -M main
git push -u origin main
```

1. اذهب إلى: Settings → Pages

3. Branch: **main**
4. Folder: **(root)**
5. اضغط Save

**انتظر دقيقة أو دقيقتين** ثم سيكون المشروع متاحاً على:

## 🆘 معالجة المشاكل الشائعة

### المشكلة: الملفات لم تظهر على GitHub Pages
**الحل:**
- تأكد من تفعيل GitHub Pages
- تحقق من الفرع الصحيح (main)
- انتظر 5 دقائق لإعادة البناء

### المشكلة: الأنماط لا تظهر بشكل صحيح
**الحل:**
- تحقق من المسار الصحيح للـ CSS
- امسح cache المتصفح (Ctrl+Shift+Delete)
- إعادة تحميل الصفحة

### المشكلة: الواجهة لا تستجيب
**الحل:**
- تحقق من وحدة التحكم (F12)
- تأكد من تحميل جميع ملفات JS
- اختبر في متصفح آخر
