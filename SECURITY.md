# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in REFLEXA, please report it
**privately**. Do **not** open a public GitHub issue for security problems.

- 📧 Email: **hanodeking15@gmail.com**
- Subject: `REFLEXA SECURITY` + a short title

Please include:
- A description of the issue and its impact
- Steps to reproduce (proof-of-concept if possible)
- The affected component (web app / Cloudflare Worker / admin)

### What to expect
- Acknowledgement within a few days.
- We will investigate and, if confirmed, work on a fix.
- Please give us reasonable time to remediate before any public disclosure.

## Scope
- Web app: https://lhk96l.github.io/reflexa/
- License API (Cloudflare Worker): `*.workers.dev`

## Out of scope
- Automated scanner output without a demonstrated, exploitable impact
- Denial-of-service / volumetric attacks
- Findings that require physical access or a compromised device
